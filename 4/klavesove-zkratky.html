Klávesové zkratky

Mise s Bludišťákem – poprvé trénujeme rychlé klávesy (Windows).

Krok 1 / 8

1) Poznej a vyzkoušej

Klávesová zkratka = stiskneš dvě klávesy najednou. Bludišťák ti ji ukáže – ty ji jen zkusíš stisknout. Nemusíš nic umět předem.

2) Zapamatuj si – tahák je tu

Teď zkusíš vybrat zkratky. Můžeš koukat na tahák. Po kontrole uvidíš jen počet chyb.

Tahák – koukej sem
  • Ctrl + C = kopírovat
  • Ctrl + V = vložit
  • Ctrl + Z = zpět
  • Ctrl + S = uložit
  • Ctrl + A = označit vše
  • Ctrl + X = vyjmout
  • Shift + písmeno = velké písmeno
Bludišťák tip: nejdřív zkontroluj

3) Pexeso 4 × 4

Otoč dvě kartičky. Najdi dvojici: zkratka + co dělá.

Nalezeno: 0 / 8

4) Pexeso 5 × 5

Větší hrací plán! Bonusová kartička Bludišťáka se počítá hned. Můžeš koukat na tahák.

Tahák – koukej sem
  • Ctrl + C = kopírovat
  • Ctrl + V = vložit
  • Ctrl + Z = zpět
  • Ctrl + Y = krok dopředu
  • Ctrl + S = uložit
  • Ctrl + A = označit vše
  • Ctrl + X = vyjmout
  • Ctrl + F = najít
  • Shift + písmeno = velké písmeno
  • Home = na začátek řádku
  • Enter = nový řádek
  • Backspace = smazat znak vlevo
Nalezeno: 0 / 12

  • Ctrl + Z = zpět
  • Ctrl + S = uložit
  • Ctrl + A = označit vše

  • Ctrl + F = najít
  • Shift + písmeno = velké písmeno
Bludišťák tip: nejdřív zkontroluj
